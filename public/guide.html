دليل ربط رقم تاجر جديد

اتبع الخطوات بالترتيب. كل زر يفتح الصفحة المطلوبة مباشرة.
العودة للوحة الإدارة

المرحلة أ: إعداد Meta للتاجر

1. فتح Business Portfolio للتاجر
ادخل بحساب التاجر، واختر Portfolio الخاص بمتجره. إن لم يكن موجوداً أنشئ واحداً باسم المتجر.
فتح Business Suite
2. تحديث معلومات النشاط
أضف معلومات الاتصال (البريد، الهاتف، الموقع إن وُجد). بدونها يرفض Meta إنشاء حساب الواتساب.
معلومات النشاط
3. إنشاء حساب واتساب للأعمال وإضافة الرقم
من Accounts > WhatsApp accounts اضغط Add، واختر Add a new number. أدخل رقماً لم يُستخدم في واتساب من قبل، ثم تحقق منه برمز (رسالة أو مكالمة).
حسابات واتساب

المرحلة ب: تطبيق العميل وتوكن دائم

4. إنشاء تطبيق للعميل
Create App ثم Business. اختر حالة الاستخدام Connect with customers through WhatsApp، واربطها بـ Portfolio التاجر.
فتح Meta Apps
5. إنشاء System User
أضف مستخدم نظام باسم متجر العميل بدور Employee، وامنحه التطبيق وحساب الواتساب بصلاحية Full control.
System Users
6. توليد التوكن الدائم
من المستخدم اضغط Generate token، واختر تطبيق العميل، وفعّل الصلاحيات: whatsapp_business_management و whatsapp_business_messaging. انسخ التوكن فوراً، فلن يُعرض مرة أخرى.
لا ترسل التوكن في أي محادثة أو رسالة. الصقه مباشرة في لوحة الإدارة.
7. جلب معرّف الرقم ومعرّف الحساب
Phone Number ID من صفحة API Setup لتطبيق العميل. WABA ID من تفاصيل حساب الواتساب داخل Portfolio.
API Setup للتطبيق
8. اشتراك التطبيق في حساب الواتساب
في Graph API Explorer اختر تطبيق العميل وغيّر الطريقة إلى POST، واكتب المسار:
{WABA_ID}/subscribed_apps
النتيجة المطلوبة: success: true. إن ظهر data: [] فلم يُنفَّذ الاشتراك بعد.
Graph API Explorer

المرحلة ج: في لوحة الإدارة

9. ربط الرقم بالتاجر
افتح التاجر في لوحة الإدارة، واجعل نوع الاستقبال رقم خاص، ثم الصق Phone Number ID والتوكن الدائم، واضغط ربط وفحص.
فتح لوحة الإدارة
10. التأكد من الحالة
يجب أن تظهر الحالة متصل ✅ مع رقم التاجر واسم الحساب.

المرحلة د: اختبار سريع

11. اختبار الاستقبال والرد
من رقم مختبَر أرسل مرحبا إلى رقم التاجر. يجب أن يصله الترحيب، ثم أرسل كلمة من كلمات المتجر ليصله الرد.
12. إعطاء التاجر ما يحتاجه
أرسل له رسالة الترحيب الجاهزة، وأخبره أن يضيف ردوده من داخل المنصة أو يرسلها لك لإضافتها.
رسائل البوت

ملاحظات مهمة

التوكن المؤقت من صفحة API Setup ينتهي خلال ساعات، ولا يُستخدم مع التاجر الحقيقي. استخدم دائماً توكن System User.
رقم الاختبار من Meta يستقبل فقط من أرقام مضافة كمستلمين مختبَرين. الرقم الحقيقي للتاجر يستقبل من الجميع بعد اكتمال التحقق.
عند الفشل: إن لم تصل رسالة للبوت، تحقق من أن حدث messages مفعّل، وأن الاشتراك في الحساب نتيجته success: true، ثم افحص سجلات Vercel بحثاً عن POST /api/webhook.
